# Масштаб колеса вагона 30639: CV-перебор `wheel_k_30639`

`wheel_k_30639` задаёт коэффициент перевода скорости колёсной тележки в м/с:
`v [м/с] = v_raw [км/ч] / K`. В `Params` (`core/config.py`) стоит `wheel_k_30639 = 3.59`.

## Откуда берётся K

1. `wheel_scale_noise.py` оценивает K прямо по данным: медиана по сессиям из взвешенного МНК
   `v_колёс / v_GNSS` на участках равномерного хода. Для 30639 получается **3.586**.
   В оценку вошли 8 сессий от 2026-08-26 (K от 3.584 до 3.590). Две сессии от 2026-05-05
   (3.622 и 3.633) отброшены как выбросы, потому что у этого вагона K между днями изменился.
   Для 30618 выходит 3.597 (49 сессий), в целом по парку 3.596. Отсюда `wheel_k_30618 = 3.597`
   и `wheel_k = 3.595` (для неизвестного вагона).
2. У 30639 есть только 11 eval-сессий за два дня, и дни не согласуются между собой. Поэтому
   окончательное значение выбрано сквозным прогоном всего конвейера (replay, затем оценка как у
   жюри) по сетке вокруг медианы RTK.

## Команды

Обе команды по отдельности выполняются примерно за 20 с на 4 процессах.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
PY=python3   # любой python 3.10+ с numpy, scipy, pyyaml

# вариант 1: одной командой (таблица, разбивка по дням и leave-one-day-out)
$PY tools/calibration/cv_sweep.py --param wheel_k_30639 \
    --values 3.585,3.59,3.595,3.60,3.605 --bags 'eval&vehicle:30639' --cv --jobs 4

# вариант 2: то же самое через tools/run_cv.py, по одному тегу на значение
for K in 3.585 3.59 3.595 3.60 3.605; do
  $PY tools/run_cv.py --tag k30639_$K --bags 'eval&vehicle:30639' --jobs 4 --set wheel_k_30639=$K
done
$PY tools/run_cv.py --compare k30639_3.59 k30639_3.595      # попарное сравнение по сессиям
```

Результат варианта 1 записывается в `$CALIB_WORK/cv_sweep/wheel_k_30639.json`
(по умолчанию это `.work/calibration/`). Вариант 2 пишет в `results/k30639_<K>/summary.md`.

## Вывод

- Плато узкое, но пологое: между 3.59 и 3.595 разница 0.5 %. Отклонение K на ±0.01 (0.3 %)
  ухудшает score_loss на 5–12 %, так что точность K важнее любого другого параметра этого вагона.
- Выбрано 3.59. Это оптимум по среднему для 8 сессий августа, которые согласуются с медианой RTK
  3.586. Сессии мая (K около 3.62–3.63) тянут оценку вверх.
- Leave-one-day-out с двумя днями ничего не даёт: каждый день выбирает своё значение
  (3.59 и 3.605). Это честное ограничение: K вагона меняется во времени (например, после обточки
  колёс), а фиксированный K по номеру вагона такие изменения не отслеживает. Частично это
  компенсирует TRN: оценка масштаба `eps` в диапазоне ±1.5 % (`trn_eps_range`).
